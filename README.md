# MINDSETU NER - Python Prototype

## Run locally

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the app:
   `streamlit run app.py`
5. Open the local URL shown by Streamlit.

## Prototype features
- User profile with English/Hindi/Marathi selection
- Adaptive memory sequence game
- Pattern recall game
- Personal baseline
- Simple unusual-change flag for caregiver review
- Daily reminders
- Caregiver dashboard
- SQLite local database
- Offline-friendly local data storage

## Important
This is a prototype for SIH demonstration. It is not a diagnostic medical device and should not be presented as diagnosing dementia.
